# 개발자 웹 이력서 제작 로드맵

## 프로젝트 개요
HTML, CSS, JavaScript, Tailwind CSS로 제작하는 정적 1페이지 개발자 이력서(웹 프로필) 사이트.
백엔드/빌드 도구 없이 브라우저에서 바로 열리는 형태로 제작한다.

## 기술 스택
- HTML5
- CSS3 (Tailwind 유틸리티 클래스로 보완이 어려운 부분만 별도 작성)
- JavaScript (다크모드 토글, 스크롤 애니메이션 등 소규모 상호작용)
- Tailwind CSS (CDN `<script>` 태그로 로드, 별도 빌드 설정 없음)

## 폴더 구조 (예정)
```
resume/
├── index.html
├── css/
│   └── styles.css
└── js/
    └── app.js
```

## 이력서 구성 내용 (일반적인 내용)
1. **헤더/프로필**
   - 이름, 직무(예: Frontend Developer), 한 줄 소개
   - 프로필 사진(선택), 연락처(이메일), GitHub/LinkedIn 링크
2. **자기소개(About)**
   - 3~4문장 정도의 간단한 소개 문단
3. **기술 스택(Skills)**
   - 언어/프레임워크/툴을 뱃지 또는 태그 형태로 나열
4. **경력/프로젝트(Experience & Projects)**
   - 프로젝트명, 기간, 한 줄 설명, 사용 기술, 링크(데모/저장소)
   - 2~3개 정도의 대표 프로젝트 카드
5. **학력(Education)**
   - 학교명, 전공, 재학/졸업 기간
6. **자격증/수상(선택, Certificates)**
   - 있는 경우에만 간단히 나열
7. **연락하기(Contact / Footer)**
   - 이메일, SNS 링크, "Get in touch" 버튼 정도

## 개발 단계

### 1단계 — 초기 세팅
- [ ] 폴더/파일 구조 생성 (`index.html`, `css/styles.css`, `js/app.js`)
- [ ] `index.html`에 Tailwind CDN 스크립트 추가
- [ ] 기본 HTML 뼈대 작성 (시맨틱 태그: header, main, section, footer)

### 2단계 — 레이아웃 & 마크업
- [ ] 헤더(이름/직무/소개) 섹션 마크업
- [ ] Skills 섹션 마크업 (태그 리스트)
- [ ] Projects 섹션 마크업 (카드 반복 구조)
- [ ] Education 섹션 마크업
- [ ] Footer/Contact 섹션 마크업

### 3단계 — 스타일링 (Tailwind)
- [ ] 반응형 그리드/플렉스 레이아웃 적용 (모바일 우선)
- [ ] 컬러 테마 및 타이포그래피 통일
- [ ] 카드 호버 효과, 여백/정렬 다듬기
- [ ] `styles.css`에는 Tailwind로 표현이 어려운 것만 작성 (예: 커스텀 애니메이션)

### 4단계 — 인터랙션 (JavaScript)
- [ ] 다크모드 토글 버튼 구현 (localStorage에 선택값 저장)
- [ ] 스크롤 시 섹션 페이드인 애니메이션(선택)
- [ ] 모바일 메뉴 토글(필요 시)

### 5단계 — 콘텐츠 채우기
- [ ] 실제 이력 정보로 텍스트/링크 교체
- [ ] 프로젝트 카드에 실제 프로젝트 3개 내용 작성

### 6단계 — 점검 & 배포
- [ ] 다양한 화면 크기에서 반응형 확인 (모바일/태블릿/데스크탑)
- [ ] 접근성 점검 (alt 텍스트, 명도 대비, 시맨틱 태그)
- [ ] GitHub Pages 등 정적 호스팅에 배포

## 참고
- 빌드 도구/패키지 매니저 없이 순수 HTML/CSS/JS + Tailwind CDN만 사용
- 자동화 테스트는 없으며, 브라우저에서 직접 확인하며 검증
